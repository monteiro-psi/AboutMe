# 1. Introdução 📜
- Uma página criada com o objetivo de fazer uma breve introdução sobre mim, e também mostrar os meus projetos mais recentes.

# 2. Tecnologias Utilizadas 💻
- HTML, CSS, Javascript

# 3. Estrutura do site 🧱
- `home`: Breve saudação e apresentação da minha área
- `projects`: Projetos mais recentes que já estão publicados aqui no GitHub
- `about`: Uma pequena biografia sobre mim.
- `contact`: Redes sociais onde me contactar.

# 4. Dificuldades e soluções ❓
- Tive dificuldades em usar a `navbar` do Bootstrap, então optei por usar a `navbar` do Flowbite: `<link href="https://cdn.jsdelivr.net/npm/flowbite@4.0.1/dist/flowbite.min.css" rel="stylesheet" />`
